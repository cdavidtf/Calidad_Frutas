# 🍎 AI Fruit Quality Classifier (Clasificador de Calidad de Frutas) 🥑

¡Bienvenido! Este proyecto es una aplicación web interactiva que utiliza **Inteligencia Artificial** para evaluar y clasificar el estado de madurez y calidad de diferentes frutas en tiempo real a partir de imágenes.

La interfaz gráfica está construida completamente con **Streamlit** y el motor de IA corre bajo **TensorFlow / Keras**.

---

## 🚀 Características del Proyecto
*   **Clasificación en segundos:** Sube una fotografía de la fruta desde tu computadora o celular y el modelo te dirá su estado.
*   **Red Neuronal Convolucional (CNN):** Utiliza un modelo de Deep Learning entrenado específicamente para reconocer patrones de frescura, madurez o daños en las frutas.
*   **Interfaz Web Intuitiva:** Diseñada para ser rápida, responsiva y fácil de usar para cualquier usuario.

---

## 🛠️ Tecnologías Utilizadas
*   **Python 3.12** (Lenguaje principal)
*   **Streamlit** (Para la creación de la interfaz de usuario web)
*   **TensorFlow / Keras** (Para la carga del modelo de Inteligencia Artificial)
*   **Pillow (PIL) & OpenCV** (Para el procesamiento y redimensionamiento de las imágenes)
*   **NumPy** (Para el manejo de los arreglos de datos del modelo)
